Подробное описание

Алфавит и упорядоченный список правил.

Инвариант: образец и замена каждого правила состоят только из символов алфавита. Порядок правил определяет их приоритет.

Формат текстового представления (см. load() и operator<<):

# комментарий
alphabet: ab
tape: baba
ba -> ab
a ->. b
