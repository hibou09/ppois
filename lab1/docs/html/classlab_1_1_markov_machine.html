Подробное описание

Машина = программа + лента (строка) + состояние выполнения.

Шаг алгорифма: берётся первое по порядку применимое правило, в строке заменяется самое левое вхождение образца. Работа заканчивается, если применена заключительная подстановка или ни одно правило не применимо.

Класс не взаимодействует с консолью: вывод состояния идёт в потоки, а построчный лог формирует вызывающий код.
