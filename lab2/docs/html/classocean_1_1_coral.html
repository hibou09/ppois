◆ grow()

double ocean::Coral::grow ( const WaterParameters & water)

Рост за сутки при данных параметрах воды.

Выше kBleachingTemperature здоровье падает на 10%, при падении ниже 50% колония обесцвечивается; иначе необесцвеченная колония растёт на 2%.

Аргументы
waterПараметры воды.
Возвращает
Новая площадь, см².
