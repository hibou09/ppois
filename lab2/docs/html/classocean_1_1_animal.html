void ocean::Animal::feed ( FoodItem & food,
double kg,
const Date & today )

Кормит животное.

Голод снижается пропорционально отношению kg к суточной норме; при кормлении сытого животного масса немного растёт (перекорм).

Аргументы
foodПартия корма.
kgКоличество, кг (> 0).
todayТекущая дата.
Исключения
InvalidParameterExceptionесли kg <= 0.
ExpiredProductExceptionесли корм просрочен.
InsufficientFoodExceptionесли корма в партии не хватает.
