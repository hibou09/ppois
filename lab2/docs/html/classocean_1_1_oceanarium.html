Подробное описание

Океанариум — корневой объект модели.

Владеет аквариумами и сотрудниками и объединяет кассу, склад корма, журнал обслуживания, расписания, бюджет и расчёт зарплаты.

◆ transferAnimal()

void ocean::Oceanarium::transferAnimal ( int animalId,
int fromTankId,
int toTankId )

Переводит животное между аквариумами (с откатом при ошибке).

Аргументы
animalIdИдентификатор животного.
fromTankIdАквариум-источник.
toTankIdАквариум-приёмник.
Исключения
InvalidParameterExceptionесли аквариумы совпадают.
TankNotFoundExceptionесли один из аквариумов не найден.
AnimalNotFoundExceptionесли животного нет в источнике.
Заметки
Если приёмник не принял животное (например, IncompatibleSpeciesException или TankCapacityExceededException), оно возвращается в источник, а исключение пробрасывается.
